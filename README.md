# kb99-1c-mini-sklad

Учебная конфигурация 1С, созданная по главам 1–10.

В проекте реализованы:
- справочники **Товары** и **Контрагенты**;
- документы **Поступление** и **Реализация**;
- СКД-отчёт «Обороты по товарам» + печатная форма документа **Реализация**.
- базовые движения документов **Поступление** и **Реализация** по регистру **ОстаткиТоваров**;
- базовое движение документа **Реализация** по регистру **ОборотыТоваров**;
- подсистема **Мини-Склад** с командами на панели.

## Как открыть

1. Скачать репозиторий.
2. Открыть конфигурацию в **1С:Предприятие 8.3** через Конфигуратор.
3. Загрузить конфигурацию из файлов.

Проект предназначен для учебных целей.
